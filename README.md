# Проект Чат (Монорепозиторий)

Проект состоит из фронтенда на Vite + React и бэкенда на Node.js + Express + Prisma.

## Переменные окружения (.env)

В проекте используются **составные переменные окружения** для гибкой настройки портов и протоколов связи:

- **Фронтенд (`apps/front/.env`)**: Содержит базовые переменные хоста и порта, из которых автоматически собираются составные ссылки `VITE_HTTP_URL` (для обычных API-запросов) и `VITE_WS_URL` (для работы чата в реальном времени через WebSockets).
- **Бэкенд (`apps/back/.env`)**: Хранит конфигурацию портов приложения и прямую ссылку подключения для ORM Prisma (`DATABASE_URL`).
- **Шаблоны (`.env.example`)**: В обеих папках созданы файлы-примеры без секретных данных, чтобы другие разработчики могли легко развернуть проект локально.

## Инструкция по запуску базы данных (Docker)

Для локальной разработки используется база данных **PostgreSQL 15**, запущенная в изолированном контейнере Docker.

### 1. Запуск контейнера

Для поднятия базы данных выполните команду из корня проекта:

```bash
docker compose up -d
```

_Контейнер автоматически считает доступы (пользователя и пароль) напрямую из `.env` файла бэкенда через директиву `env_file`._

### 2. Проверка статуса базы данных

Чтобы убедиться, что контейнер успешно запущен и работает, выполните:

```bash
docker compose ps
```

**Ожидаемый результат:** Контейнер `chat-db-1` должен быть в статусе `Up` или `running`, а порт компьютера `5433` должен быть успешно перенаправлен на внутренний порт базы `5432` (`0.0.0.0:5433->5432/tcp`).

### 3. Проверка подключения (Prisma Studio)

Чтобы протестировать связь бэкенда с запущенной базой данных, перейдите в папку бэкенда и запустите панель управления Prisma:

```bash
cd apps/back
npx prisma studio
```

После этого в браузере откроется веб-интерфейс, подтверждающий успешную синхронизацию таблиц чата с СУБД.
