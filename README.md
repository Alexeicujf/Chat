# Проект Чат (Монорепозиторий)

Проект представляет собой полнофункциональный чат с разделением на фронтенд (Vite + React) и бэкенд (Node.js + Express + Prisma). Вся инфраструктура полностью контейнеризирована.

## Переменные окружения (.env)

В проекте реализована концепция **составных переменных окружения** для гибкой настройки портов и протоколов связи:

- **Фронтенд (`apps/front/.env`)**: Содержит базовые переменные хоста и порта, из которых автоматически собираются составные ссылки `VITE_HTTP_URL` (для обычных API-запросов) и `VITE_WS_URL` (для работы чата в реальном времени через WebSockets).
- **Бэкенд (`apps/back/.env`)**: Хранит конфигурацию портов приложения и прямую ссылку подключения для ORM Prisma (`DATABASE_URL`).
- **Шаблоны (`.env.example`)**: В обеих папках созданы файлы-примеры без секретных данных для безопасного хранения в репозитории.

## Инфраструктура и запуск проекта (Docker)

Весь проект — **фронтенд, бэкенд и база данных** — собирается и запускается одной общей командой благодаря настроенным `Dockerfile` в каждом приложении и общему `docker-compose.yml`.

### Быстрый запуск всего приложения:

Из корня проекта выполните команду для сборки и запуска всех контейнеров в фоновом режиме:

```bash
docker compose up -d --build
```

### Сервисы в контейнерах:

1.  **`db` (PostgreSQL 15)**: Работает на порту `5433` хоста. Настроен Docker Volume (`pararara`) для персистентного хранения сообщений и пользователей чата. Автоматически подтягивает креды из `.env` бэкенда.
2.  **`backend` (Express + Prisma)**: Работает на порту `8080`. Запускается строго после поднятия базы данных (`depends_on`). Внутри контейнера автоматически генерируются типы Prisma (`prisma generate`).
3.  **`frontend` (Vite + React)**: Работает на порту `5173`. Запускается в режиме `--host`, пробрасывая интерфейс наружу для разработчика.

### Проверка статуса запущенных сервисов:

```bash
docker compose ps
```

**Ожидаемый результат:** Все три контейнера (`chat-db-1`, `chat-backend-1`, `chat-frontend-1`) должны иметь статус `Up`.
